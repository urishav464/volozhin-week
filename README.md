# שבוע וולוז'ין

מערכת לתכנון ולשיבוץ של שבוע וולוז'ין, במדרשה הגבוהה עין פרת. המשימות שלה:
- רשת השבוע, שאליה משבצים מרצים בגרירה;
- איזון מגדרי ונושאי לכל יום;
- מניעת פנייה כפולה ושיבוץ כפול;
- תוצרים שנגזרים מרשומה אחת: גיליון מעקב, רשימת מלווים, הודעת סיכום למרצה, ייצוא למעצבת, המקראה ורשימות לוגיסטיקה;
- שימור הידע משנה לשנה.
